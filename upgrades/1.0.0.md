# 1.0.0

Action required: yes, once

The first versioned release. Nothing in the blueprint changed; this file only
brings a project that predates versioning onto the version line.

## 1. Record the version

- **Find:** the project's root `claude.md` has no `blueprint_version` line in
  its configuration block.
- **Change:** add `blueprint_version: 1.0.0` to that block.
- **Check:** the line is there, and `blueprint/VERSION` reads `1.0.0` or
  newer.

## 2. See where the project stands (ask before fixing anything)

Projects that predate versioning were pinned to different commits, so there is
no single list of differences to apply. Run the
[blueprint audit](../skills/blueprint-go-audit/SKILL.md) with the whole project as its
scope and show the user the result.

Do not fix the findings as part of this upgrade. Which ones to fix, and when, is
the user's decision.
